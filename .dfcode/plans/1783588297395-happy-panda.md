# Improve AGENTS.md for the PathPlanningwithEnergy repo

## Context
The repo already has a solid `AGENTS.md` (165 lines) covering code style, naming,
error handling, and the coordinate system. Three gaps make it stale for coding agents:

1. **Missing tests** — 6 offline test files are undocumented:
   `test_planning_simulation.py`, `test_rrt_mock_2d.py`, `test_arc_blend_zigzag.py`,
   `test_bspline.py`, `test_dubins_3d.py`, `test_mapping_and_planning.py`.
2. **Single-test guidance is buried** — the "run one test" recipe is a comment inside
   the command block, easy to miss.
3. **Dependency gap** — `requirements.txt` omits `scipy`, though `mapping/esdf.py`
   imports it. Agents that trust requirements.txt will hit an ImportError.

No Cursor rules (`.cursor/rules/`, `.cursorrules`) or Copilot rules
(`.github/copilot-instructions.md`) exist, so there is nothing extra to fold in.
A root `CLAUDE.md` (337 lines) holds deep architecture detail worth cross-referencing.

## Approach
Targeted improvement — preserve the well-tuned Code Style / Naming / Error Handling /
Coordinate System sections verbatim, and only touch the top (Build & Run) area:

- Split the command list into **Offline tests**, **AirSim-required**, and **Analysis**
  groups so agents know what they can run without the simulator.
- Add all 6 undocumented offline tests to the Offline group.
- Promote the single-test recipe to its own **"Running a single test"** subsection.
- Add a one-line note that `scipy` must be installed even though it's absent from
  `requirements.txt`.
- Add one line near the top pointing to `CLAUDE.md` for deeper module/architecture detail.

Keep total length ~150 lines. No other sections change.
