# 课题定义(定稿)

## 题目
面向无人机能耗建模的**可信大模型自动化研究框架**——真实数据锚定评测与能力边界刻画

（英文候选:*A Trustworthy LLM-Agent Autoresearch Framework for UAV Energy Modeling: Real-Data-Anchored Evaluation and Capability-Boundary Characterization*）

## 一句话定位（防翻车基线）
**不**提出新算法、**不**声称"更强的优化器"。贡献 = 一个**防作弊、真实数据锚定、会诚实报负结果**的 LLM 自动化研究框架，在无人机能耗（真实 DJI M100）上验证，并**诚实刻画** LLM 自动化研究相对简单基线的真实能力边界。

## 三个创新点（全诚实）
1. **工程/方法论**：可信自动化研究框架——冻结的、锚定真实 DJI 功率（P=V·|I|）的作弊不了评测器 + 按飞行 held-out + 诚实报负结果。对标 2026 热点（PseudoBench 等"AI 自动研究不可信"）。
2. **应用（UAV）**：真机数据上自动发现比经典稳态 BEMT 准 **73%** 的能耗模型（留出能量 ARE 6.88%→1.86%），作为**可信能耗代价**接入能量感知路径规划（原仓库场景）。
3. **实证/能力边界**：系统证明"在这类成熟问题上，LLM 自动化研究的**优化性能 ≈ 随机/贪心简单基线**（随机搜索追平 loop）；LLM 真价值在 ①开放代码空间生成 ②可信度，而非调参性能"。—— 一个诚实严谨的能力边界研究。

## 为什么站得住
- 不碰"新算法/更强优化器"这两个会被一问就崩的点；
- 每条创新点都有 git 可查的实验证据（M100 真数据、held-out、baseline 对比、负结果）；
- **把最尖锐的质疑（"CC+loop 和普通循环有啥区别"）变成论文的 finding**——诚实回答"LLM 自动化研究强在哪、不强在哪"本身是合法且及时的贡献。

## 对应已建（autoresearch/energy_m100/ + autoresearch/radar/）
- `energy_m100/m100_eval.py`：冻结评测器（真实功率真值，held-out，能量 ARE）——**创新点1的核心**。
- `energy_m100/autoresearch_energy_real.py` + `baselines_energy.py`：loop + 生死线/必要性——**创新点2、3**。
- `energy_m100/candidate_energy.py`：沙箱可进化能耗模型组件——"开放代码空间"的载体。
- `radar/*`：**第二个域（感知/跟踪）的方法论验证**——证明框架域无关（可作次要章节，或按导师取舍）。

## 明确不声称（诚实边界，写进"局限"）
- 不是新能耗/规划/跟踪算法；
- CC+loop 不比普通优化循环（随机/网格/BO）在调参性能上更强（本文实证如此）；
- per-sample 功率不可精确预测（5Hz 噪声）；只声称 per-flight 能量与相对改进；
- 能量感知规划的增益是"相对 + 真实模型锚定"，非绝对最优。
